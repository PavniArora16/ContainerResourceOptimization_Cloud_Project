# Dataset

This folder contains dataset details and (later) the actual data used for model training/testing.

## Planned Dataset
Public cluster/workload trace dataset (e.g., Google Cluster Usage Traces or similar), used for training the resource demand prediction model.

## Contents
- `raw/` — original unprocessed data
- `processed/` — cleaned and preprocessed data
- `dataset_description.pdf` — dataset name, source, size, records, features, license, and preprocessing steps

## Status
Dataset selection and description in progress.
